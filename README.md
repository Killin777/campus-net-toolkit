# 校园网工具箱

> 校园网环境下的**代理开关**与**网络诊断**工具。
> 它不加速、不提速——它做的是：告诉你网络哪里出问题，并保证代理开关前后状态干净。
>
> **本工具不提供任何代理服务或线路。** 代理能力来自你自己安装并配置的客户端。

Windows 10 1809+ / Windows 11，Windows PowerShell 5.1 + .NET Framework 4.8，无第三方依赖。

---

## 它做什么

| 能力 | 说明 |
|---|---|
| **校园网一键登录** | 自动切到配置的校园 WiFi → 等联网 → 需要时先切国内直连 → 用默认浏览器打开认证页 |
| **开启代理** | 五层验证（端口/协议/转发/出口/系统代理一致性）通过后才开启；内核没跑会自动拉起 |
| **国内直连** | 关系统代理 + 恢复自动 DNS + 检查 TUN 与 VPN 是否抢路由 |
| **一键体检** | 网关延迟、公网延迟、抖动、丢包、路由守卫、断链统计 |
| **校园网体检** | 认证状态、DNS 归属、IPv6、MTU、代理绕过、信号；不在校园网时会明确说明 |
| **路由守卫** | 虚拟网卡抢占、TUN 与系统代理双开、端口对内网开放、代理残留、PAC 冲突 |
| **断链取证** | 近 7 天断链分布，可导出报告用于报修 |

## 它明确不做

- 不做游戏加速（没有线路资源，那是商业加速器的生意）
- 不碰"注册表 TCP 神油"（微软文档说协议栈是自适应的）
- 不代填账号密码、不保存凭据、不绕认证、不共享网络
- 不承诺降低延迟——物理链路和 AP 故障不是软件能改的

## 下载与运行

从 [Releases](https://github.com/Killin777/campus-net-toolkit/releases) 下载 `网络优化器.exe`，双击即可。

EXE 内置全部程序资源，**可单独复制使用**，不需要安装任何运行库。

首次启动会让你选择是否以后默认以管理员权限运行：

- **是** → 记住偏好，之后按 Windows 规则请求 UAC
- **否** → 以普通权限打开（部分功能不可用，如改 DNS、停服务）
- **取消** → 退出，不保存

窗口右上角显示当前权限；普通权限下可点它申请一次性提权。

## 界面导览

顶部三个按钮：

```
[开启代理]  [国内直连]  [⚙ 设置]
```

**高亮跟随真实状态**：系统代理开着就亮「开启代理」，关着就亮「国内直连」。即使你在 Clash Verge 里改了，这里也会跟着变。

中间状态区显示：

```
已连接代理 / 系统代理已开启 / 代理目标连接失败 / 系统代理已关闭
127.0.0.1:7897 · TCP 可连接，出口需另行验证
```

十个功能按钮：

| 按钮 | 作用 |
|---|---|
| 一键体检 | 延迟 / 抖动 / 丢包 / 信号 / 断链，约 8 秒 |
| 校园网体检 | 认证 / DNS / IPv6 / MTU / 代理绕过 / 信号，约 15 秒 |
| DNS 优选 | 实测内网与公共 DNS 的响应速度，选最快 |
| 延迟测试 | 连续采样并画曲线，看是否稳定 |
| 路由守卫 | 查虚拟网卡抢占 / TUN 双开 / 端口暴露 / 代理残留 |
| 校园网登录 | 自动切校园 WiFi 并用浏览器打开认证页 |
| 网络急救 | 清代理残留 / 刷 DNS / 续租 IP / 必要时重启网卡 |
| 打开代理软件 | 启动设置里配置的客户端 |
| 导出诊断报告 | 生成带断链时间点的文本，便于报修 |
| 还原与备份… | 从 `runtime/` 备份还原 DNS / 跃点 / 传递优化 |

底部那行字可以点，打开完整使用说明。

## 校园网登录：它到底做了什么

```
点「校园网登录」
  ↓
① 读配置里的 ssid（如 Campus-WiFi）
   已经在上面          → 跳过
   扫描范围内没有       → 提示"你可能不在校园内"
   有已保存配置         → netsh wlan connect
   没有配置 + ssidOpen  → 自动生成开放网络配置并导入（不涉及密码）
   然后轮询等待关联，最多 20 秒
  ↓
② 连上了且能直连上网 → "无需认证"，不弹浏览器
  ↓
③ 认证页可达吗？不可达 → 弹窗问你是否仍然打开
  ↓
④ 系统代理开着 → 先切国内直连（认证页在校内网段，走代理必打不开）
  ↓
⑤ 默认浏览器打开认证页，账号密码由你自己输入
```

配置在 `config/campus-config.json`：

```json
{
  "portalUrl": "http://10.0.0.1/0.htm",
  "ssid": "Campus-WiFi",
  "ssidOpen": true,
  "internalNets": ["172.18.", "172.21.", "172.22."]
}
```

- `portalUrl` 认证页地址
- `ssid` 校园 WiFi 名称，留空则不做自动切换
- `ssidOpen` 只有明确标记为**开放网络**时才允许自动创建配置
- `internalNets` 用于判断"是否在校园网"

## 开启代理：验证不通过就不开

```
① 端口在监听吗？没有 → 读设置里的客户端路径并启动，最多等 45 秒
② 端口通了但转发没就绪 → 重试 4 次，每次隔 4 秒
③ 五层验证：端口 → 协议 → 转发 → 出口 → 系统代理一致性
④ 设系统代理 → 等 2 秒复核（客户端常会把它改回去，被改回就再设一次）
```

日志会逐条列出每一步的结果。失败时告诉你是哪一层，而不是笼统的"失败"。

## 网络列表：断网自动重连

「⚙ 设置 → 网络列表…」维护自己信任的网络。

| 列 | 含义 |
|---|---|
| 网络名称 | SSID |
| 类型 | 校园网 / 普通 |
| 认证网址 / 密码 | 校园网填认证页地址；普通网络用 Windows 已保存的密码（**本工具不保存密码**） |
| 自动重连 | 断网时是否尝试这个网络 |

操作：`添加` / `编辑` / `删除` / `设为校园网` / `设为普通`。
选中一行点「设为校园网」后，该行的"密码"栏会变成"认证网址"。

**断链判定规则**

| 情况 | 判定 |
|---|---|
| 连续不可达 **≥ 10 秒** 才恢复 | 记一次**断链** |
| 中断 < 10 秒自动恢复 | 只记**抖动**，不计入断链 |
| 工具自身重连/改配置期间 | 维护窗口内，不计入 |
| 睡眠、锁屏、手动断开 | 不计入 |

重连策略：断网 ≥10 秒后按列表顺序尝试，**60 秒内不重复尝试**，避免反复断连。
事件记录在 `%LOCALAPPDATA%\CampusNetToolkit\runtime\wifi-events.json`（最多保留 500 条）。
## 常见问题

**网页全打不开，但 QQ / 游戏正常**
→ 大概率是代理残留（系统代理指向已死的端口）。点「网络急救」或「国内直连」。

**关了代理软件，网页还是慢或异常**
→ 可能开着 TUN，系统代理开关对它无效。点「路由守卫」看第二项。

**WiFi 一断，网就"死"很久而不是立刻失败**
→ 可能 VPN 虚拟网卡接管了默认路由。点「路由守卫」看第一项。

**校园网体检说"当前不在校园网"**
→ 这个提示是对的：认证状态那类检查只在校园网内有意义。连上校园 WiFi 或插网线再跑。

**信号一直偏弱**
→ 点信号那一行重连，让 Windows 重新选 AP。想优先选信号强的频段，需改网卡的"频段偏好"参数（尚未做成一键设置）。

## 数据与回滚

```
%LOCALAPPDATA%\CampusNetToolkit\
├─ app\<版本-哈希>\      程序解包缓存，可随时删除
└─ runtime\              设置、状态、日志、备份
```

- 所有改动前都会在 `runtime/` 生成备份；「还原与备份…」可写回
- **不要清空还有待还原记录的 `runtime/`**
- `config/` 只存用户手改配置，程序只读
- 源码运行时以项目目录为数据根，可用 `-DataDirectory` 指定隔离目录

## 合规声明

本项目只做本地测量与本地配置修正，**不实现**自动登录、代填密码、保存凭据、绕过认证、破解限速、MAC 克隆、多拨、账号共享或把代理端口开放到局域网。

校园网登录只用默认浏览器打开认证页，账号密码由使用者自行输入，密码记忆交给浏览器自带的密码管理器。
**本工具不提供任何代理服务或线路**，不内置、不分发、不销售订阅或节点。所有代理能力均来自使用者自行安装、自行配置的第三方客户端；本工具只负责读写本机的系统代理设置与做网络测量。
