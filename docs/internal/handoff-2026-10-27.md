## 已知坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 改完解析报大量错误、中文乱码 | 编辑工具丢了 BOM | 跑 `tools\Format.ps1 -Fix`，再 Parser |
| 替换 exe 报 Device or resource busy | 程序正在运行 | 先重命名旧 exe 再复制；退出后可删旧文件 |
| 给 exe 传 `-Screenshot` 没反应 | 启动器只接受 `--admin` / `--startup-settings` / `--smoke-test` / `--verify-package` | 界面出图走 `src\网络优化器.ps1`；包校验走 `--verify-package <目录>` |
| 弹窗「设置 ForeColor 时发生异常」 | 有表达式返回 $null | 颜色一律 FromArgb 字面量 |
| 体检看起来没反应 | 扫描约 2 秒且结果可能为 0 项 | 现在有「正在扫描 → 耗时 → 只读检查结果」 |
| 备份失败：vEthernet 找不到 CIM 对象 | 虚拟网卡没有 IPv4 接口配置 | 已修：记入「无法读取跃点」，不再中断 |
