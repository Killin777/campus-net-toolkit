# 校园网工具箱 v1.3.2 产品审查范围

日期：2026-10-27（Asia/Shanghai）。

## 对象与目标

- 对象：当前工作区 `/mnt/d/desktop/校园网工具`，本地 `VERSION` 为 1.3.2；不据此推断远端发布包与本地完全一致。
- 主要用户：在 Windows 校园网环境中遇到认证、代理残留、掉线等问题，缺少网络排障知识的普通用户。
- 主要任务：快速判断当前哪里不通，理解下一步操作，在明确影响后修复，并能核对和撤销本工具的改动。
- 输入：README、当前源码、现有主界面/设置截图、测试覆盖说明，以及用户补充的“路由守卫选项 + 事件驱动状态栏”方案。
- 审查内容：功能定位、任务流程、状态真实性、后台检测、路由修改及还原、界面结构、文案、可达性和验证边界。

## 验收方式与边界

- 所有重要结论附源码行号、截图位置或官方技术来源。
- 区分已读源码事实、现有截图事实、静态推断和未实测项目。
- 产出问题优先级、十原则审查、一个重构方向及可验证的下一步。
- 本轮只做产品分析；不修改程序、网络设置、发布包或远端版本。
- 不读取用户配置、运行日志、备份中的个人网络信息或凭据。
- 没有运行中的界面和实际 CPU 测量时，不声称测得实时界面性能、CPU 占用或网络结果。
- 桌面 PowerShell/WinForms 产品的 JS 体积、ARIA、网页 TTI 等指标标为不适用，使用对应的桌面证据，并注明评分适配。
- 无指定竞品、品牌更新或实施期限。
