校园网工具箱 · 使用说明

【首次启动与权限】
双击网络优化器.exe。首次选择是否以后默认以管理员权限运行。
“是”记住管理员启动偏好，但 Windows 的 UAC 提示仍遵循系统规则。
“否”记住普通权限启动；“取消”退出且不保存新选择。
设置 → 启动权限…，可修改下次启动偏好。右上角的普通权限标记可申请一次性提权。
取消 UAC 不会修改网络。点 × 关闭会退出程序，点 − 最小化到任务栏。

【窗口结构】
左侧四个页面：当前网络 / 检测详情 / 逐项处理 / 更多工具。
右上角「设置」：代理客户端、端口、网络列表、DNS 列表、频段偏好、检查新版本、检测端点。
右上角权限标记：普通权限下可请求一次性提权。

【当前网络】
一个结论、证据时间、五枚状态徽章（链路 / DNS / 国内 / 国际 / 代理）和主要动作。
重新检测：请求一次完整探测；刷新状态：只刷新连接与代理状态，不重新探测。
查看检测详情：跳到五段证据页。查看断链时间线：读取无线事件日志。
检查有线连接：读取当前以太网协商速率、IPv4 出口、认证与累计计数，不调整双工、MTU 或 TCP。

【检测详情】
五段证据：链路、DNS、国内、国际、代理。
每段有状态点、证据时间和具体证据；失败段给出「→ 建议」。
分层探测还没出结果时显示「— 未验证」，不把未知写成失败。
鼠标移到「国内 / 国际」标题上会出现 ▾，点击展开每条探测链接（√/×、耗时、URL），再点收起。
探测端点可在设置里改；改完下一轮分层探测生效。

【逐项处理】
检测可处理项：扫描接口跃点与手动代理项，只读，约 2 秒。
每项显示证据、拟改值、是否需要管理员、影响，默认不勾选。
应用已选项：确认后逐项写备份、写入并读回复检；失败保留记录可重试。
处理记录：选中一条可撤销，只恢复这一项；「打开记录文件」查看对应 JSON 备份。
检查结果列表会列出全部只读检查项：√ 正常 / ! 需留意 / × 有问题。
修改接口跃点需要管理员权限；关闭手动代理不需要。

【更多工具】
检查：详细连接体检 / 校园网体检 / DNS 优选 / 延迟采样测试 / 导出诊断报告。
连接：系统代理 ▾（验证并开启 / 只关闭手动代理 / 打开代理软件）、打开校园网登录页。
修复：网络急救 ▾（一键急救 / 只重连当前 Wi-Fi / 恢复当前网卡自动 DNS）、还原与备份 ▾。
按钮下方是同页的运行日志和延迟曲线，点完按钮当场能看到输出。

【状态说明】
系统代理已开启：当前手动系统代理打开，显示地址的 TCP 连接可建立。
这不等于所有应用均走代理，也不等于代理出口持续可用。
代理目标连接失败：本次 TCP 探测未成功，先检查代理软件或网络。
系统代理已关闭：只表示手动系统代理关闭；PAC、TUN、VPN、应用内代理需单独检查。
PAC 自动代理已配置：手动代理关闭后，PAC 脚本仍可能控制部分应用。
程序定时刷新只提示，不会依据一次探测结果自动关闭代理。

【检查更新】
设置里的「启动时检查新版本」默认开启。启动后若连得上 GitHub，会比对最新 Release；
有新版会询问是否打开下载页；连不上只写一行日志，不影响使用。

【检测端点】
设置 → 检测端点…：国内 / 国际各一组，每行「名称|URL」，只支持 http/https，每层最多 8 个。
保存后下一轮分层探测生效；「恢复默认」可填回内置端点。

【还原与备份】
“还原代理 / 使用模式”恢复 proxy-backup.json、dns-backup.json 及模式中保存的状态。
普通权限可恢复仅属于当前用户的代理记录；需要恢复 DNS、服务、电源或网卡参数时需管理员。
“恢复网络备份…”选择 network-backup-*.json，恢复其中的 DNS、跃点和传递优化设置。
还原失败会保留待恢复记录，可在权限或设备恢复后重试。
已经成功消费的模式备份移到 runtime/history；手动选择的网络备份文件继续保留。
旧版备份没有记录自动/静态 DNS 来源时，只能按旧格式恢复，不能追溯缺失信息。
不要在尚未还原时删除 runtime，否则会丢失恢复依据。

【数据保存在哪里】
EXE：%LOCALAPPDATA%\CampusNetToolkit\runtime。
源码运行：工作区 runtime；也可由维护者指定隔离的数据目录。
config 是用户手改配置，程序只读；界面设置写入 runtime/proxy-settings.json。
启动偏好是 runtime/launcher.json，更新 EXE 后继续保留。
EXE 放在旧工作区首次启动时会按白名单导入旧配置及恢复记录，旧文件不移动，新记录不覆盖。

【功能边界】
只做本机可检查的诊断与配置维护，不承诺提高带宽或降低游戏延迟。
不代填或保存账号密码，不绕过校园网认证，不共享账号或网络，不提供代理资源。
AP 故障、弱覆盖、校园网出口策略等问题需要结合学校网络中心进一步处理。
游戏模式仅保留为高级 CLI 兼容操作，主界面不提供通用“一键游戏加速”入口。
