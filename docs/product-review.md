# 产品与封装检查（2026-10-26）

验收目标：单个 EXE 双击可用；首次询问并记住管理员启动偏好；默认打开界面不更改网络；所有有状态的修改先保存还原记录，失败后可以重试；支持中文、空格路径；发布包不夹带个人配置、日志、备份和快捷方式。

当前定位：面向 Windows 校园网用户的本地体检、代理管理和可还原调优工具。网络中心/AP 故障、出口策略、代理节点质量不能由本地参数调整解决。体检应先给出证据，再提供具体操作。

## 本轮工作与验收

- [ ] 将 5 KB 启动壳改为内置程序的单文件 EXE，提供可重复构建脚本。
- [ ] 首次启动提供“始终管理员 / 普通权限 / 取消”，记住选择；设置中可修改，UAC 遵循系统规则。
- [ ] 配置与还原记录独立于程序版本保存，保留源码运行入口。
- [ ] 修复 Windows 子进程参数转义、启动错误不可见和重复启动问题。
- [ ] 修复 DNS 失败计时、静态/自动状态丢失以及还原失败后清空记录的问题。
- [ ] 代理监控检测实际地址，只提示，由用户主动清理。
- [ ] 完成脚本、协议、产品逻辑、独立 EXE 与界面验证。

## 检查发现

| 优先级 | 问题与证据 | 影响 / 处理方向 |
|---|---|---|
| P1 | 原 EXE 只按相对路径启动 src，缺少构建流程 | 单独复制 EXE 无法运行，版本不能可靠复现；内置白名单资源并校验哈希 |
| P1 | GUI 定时器根据配置端口判断代理“残留”并自动关闭 | 使用其他端口/远程代理时误清理；改为实际端点检测和显式操作 |
| P1 | DNS 测速 catch 后仍记录失败用时 | 快速拒绝响应会赢过真正可用的 DNS；只计成功结果 |
| P1 | 游戏模式改无线参数未保存原值，恢复服务失败后仍清记录 | 不满足“可还原”的定位；保存原值，恢复成功才消费记录 |
| P1 | DNS 备份只保存地址，没有保存自动/静态来源 | 把 DHCP 地址错误固定，换校园网络后可能断网；保存来源标志 |
| P2 | 子进程 ArgumentList 直接拼接数组 | 目录含空格时参数断开；统一 Windows 参数编码 |
| P2 | 固定高度界面，低分辨率或较高缩放可能遮挡按钮 | 增加滚动与屏幕适配，保留现有界面结构 |
| P2 | “一键优化/游戏优化”把多种设置绑定在一起，效果未经操作前后比较 | 操作前明确影响，不承诺降低游戏延迟；后续应发展为诊断建议与用户选择步骤 |
| P2 | 主界面还包含采集、界面、系统修改和进程调度 | 分离启动、状态保存和诊断函数；后续可继续把修改操作移入独立控制器 |

## 验证边界

本轮不通过实际切 DNS、停止更新服务、重启网卡来验证，以免影响正在使用的网络。涉及这些操作的回归使用隔离状态目录与替代系统调用；发布 EXE 进行真实资源解包、路径与只读界面冒烟。UAC 安全桌面需由用户亲自选择。
